This is an example post so you can see the template in action. To add a real post that mirrors something from Medium:

1. Copy this file and rename it to `YYYY-MM-DD-your-post-title.md` inside `_posts/`.
2. Set the `title:` in the frontmatter above.
3. Paste your post's text below the `---` line, in Markdown (headings with `#`, bold with `**text**`, etc).
4. Drop any images into `assets/images/` and reference them like:

   `![alt text](/assets/images/your-image.png)`

5. Commit and push — the site rebuilds automatically.

Delete this file once you've added your first real post.
